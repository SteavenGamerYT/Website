## Introduction

So in order to install it you need

## Installer System Requirements
cpu: at lest intel 4th gen or ryzen first gen  
ram: at lest 8gb  
gpu: at lest rx 5xx or gtx 16xx  
storage: at lest 120gb ssd and usb flash drive at lest 4gb  
internet: ethernet is required  

## Step 1 (Downloading iso)

Go to https://github.com/SteavenLinux/SteavenLinuxISO/releases  
and Download newest iso Currently it is SteavenLinux-2026.09.22-x86_64.iso  

## Step 2 (Putting it on USB Flash Drive)

Copy it to ventoy flash drive  

## Step 3 (Booting the ISO from ventoy)

Boot to ventoy and boot the SteavenLinux ISO

## Step 4 (Installing SteavenLinux)

type `steavenlinuxinstall`  
Installer will open  
At first it will check for intenret, This is why you need ethernet.
![1](/images/2026/how-to-install-steavenlinux/1.png)  
![1](/images/2026/how-to-install-steavenlinux/2.png)  
Type automatic and hit enter  
![1](/images/2026/how-to-install-steavenlinux/3.png)  
Type the disk path like `/dev/sda` and hit enter  
![1](/images/2026/how-to-install-steavenlinux/4.png)  
Type your pc hostname then your timezone then locales  
For default don't type anything  
Desktop Enviroment Type `kde`, Gnome is a bit buggy  
![1](/images/2026/how-to-install-steavenlinux/5.png)  
For Cachyos, Type `yes` and hit enter  
You need to type the same password 4 times  
![1](/images/2026/how-to-install-steavenlinux/6.png)  
![1](/images/2026/how-to-install-steavenlinux/7.png)  
Type exactly as how it says `ERASE /dev/vda`  
![1](/images/2026/how-to-install-steavenlinux/8.png)  

## Step 5 (Rebooting to The Installed SteavenLinux)
And It's done  
Just type `reboot`  
To reboot to SteavenLinux  
![1](/images/2026/how-to-install-steavenlinux/9.png)  
Type your password   
![1](/images/2026/how-to-install-steavenlinux/10.png)  
Enjoy using SteavenLinux  
![1](/images/2026/how-to-install-steavenlinux/11.png)
